# Live Crypto Footer

A responsive live cryptocurrency footer that displays real-time crypto market prices using API integration.

## 🚀 Features

- Real-time cryptocurrency price updates
- API integration for live market data
- Responsive design
- Lightweight and easy to integrate
- Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Crypto API (e.g., CoinGecko / Binance)
